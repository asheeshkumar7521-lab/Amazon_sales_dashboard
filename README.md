# Amazon Sales Dashboard | Power BI

## Project Overview

This project presents an interactive Amazon Sales Dashboard created using Microsoft Power BI to analyze sales performance and business trends.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## Dashboard Preview

![Amazon Sales Dashboard](dashboard.png)

## Key Features

* Sales Performance Analysis
* Revenue and Profit Insights
* Product-wise Sales Analysis
* Category-wise Performance
* Interactive Filters and Slicers
* KPI Cards and Visualizations

## Files Included

* `.pbix` – Power BI dashboard source file
* `.png` – Dashboard preview

## How to Use

Download the PBIX file and open it using Microsoft Power BI Desktop.
